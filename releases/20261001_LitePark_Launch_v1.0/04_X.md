## Recommended: Single Post

ChatGPT history isn't a “come back later” queue, so I built one.

LitePark is a small macOS companion for parking conversations, reordering them, reopening them in ChatGPT Desktop, and marking them done.

Open source: https://github.com/victor-zhang-2026/LitePark

macOS 13+ · v1.0.0

## Thread

**1/4**

I often have useful ChatGPT conversations that I cannot continue right away. History keeps them, but it does not capture the intention: come back to this later.

So I built LitePark for macOS.

**2/4**

Press `⌃⌥L` in ChatGPT Desktop to park the current conversation.

LitePark keeps a small manual queue: reorder by dragging, click to reopen, or mark an item done.

**3/4**

I deliberately kept the scope small: a movable floating interface, local persistence, no conversation-content storage, no analytics, and no extra task-management system.

Current constraint: v1.0.0 identifies conversations by title, so rename first and avoid renaming after adding.

**4/4**

LitePark v1.0.0 is open source and available now for macOS 13+.

GitHub + download:
https://github.com/victor-zhang-2026/LitePark

Issues and workflow feedback are welcome.
