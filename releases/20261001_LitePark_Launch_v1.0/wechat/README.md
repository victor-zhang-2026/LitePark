# LitePark v1.0.0 公众号发布包

## 文件

- `article.html`：排版后的完整文章预览稿。
- `article-wechat-copy.html`：带“一键复制正文”按钮的公众号粘贴版本。
- `cover-900x383.png`：公众号头条横版封面。
- `cover-square.png`：聊天、朋友圈等方形分享封面。
- `images/product-demo-queue.png`：使用虚构对话名的真实 LitePark 界面。
- `images/litepark-logo.png`：LitePark Logo。
- `images/01-floating-workflow.png`：悬浮球在桌面上的轻量入口场景。
- `images/02-manual-order.png`：手动拖拽排序说明。
- `images/03-return-to-chatgpt.png`：从 LitePark 返回并验证 ChatGPT 对话。
- `images/04-local-privacy.png`：本地数据和隐私边界。
- `images/05-done.png`：完成后移出 Later 队列的状态说明。

## 使用

1. 浏览器打开 `article-wechat-copy.html`。
2. 点击顶部的“一键复制公众号正文”。
3. 粘贴进公众号编辑器，上传 `cover-900x383.png` 作为封面。
4. 发送预览，检查图片清晰度、GitHub 链接和段落间距。

公开图片只使用虚构 Demo 对话名，不包含真实 ChatGPT 对话、本地路径或个人信息。
