# LitePark 1.1.5 · Drag Reorder Refinement

Parking bays and striped stops now stay fixed while conversation cards move between them. The drag hint is drawn inside the floating panel, where it remains visible above the panel surface.

Download `LitePark-v1.1.5-macOS.zip`, unzip it and move `LitePark.app` to Applications. Requires Apple silicon and macOS 13+. The build uses a local development signature and is not Apple-notarized.

Release compilation, signature, archive and public-download checks are recorded separately. No new functional or native UI tests were run; the local drag interaction remains subject to the owner's manual acceptance.
