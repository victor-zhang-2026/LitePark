# LitePark 1.1.1 · Unified Light Panel

Park it now. Pick it up later.

- **Unified light panel:** the Header and Parking Board now share the same warm-white base background, so the floating window reads as one continuous panel.
- **Dark mode unchanged:** the existing dark Header, board, cards, and other colors are retained.
- **Everything else unchanged:** card layout and colors, parking-bay styling, empty-space dashes, controls, drag/hover behavior, shadows, and queue logic are preserved.

## Install

Download `LitePark-v1.1.1-macOS.zip`, unzip it, and replace `LitePark.app` in Applications. Existing saved conversations and preferences are retained.

Requires Apple silicon and macOS 13 or later. This build is signed with a local development identity and is not Apple-notarized.

## Validation

The focused Parking Board persistence and behavior suite passed 190 assertions. Release compilation, strict signature verification, installed-app identity, and public-download identity were verified for this release.
