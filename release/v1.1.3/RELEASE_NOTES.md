# LitePark 1.1.3 · Collapsed Sidebar Reopening

Park it now. Pick it up later.

- Saved conversations can reopen when ChatGPT's entire left sidebar is hidden. LitePark shows it once, selects the unique matching chat, then restores the hidden state.
- Conversation matching still requires an exact, unique visible chat title and verifies the opened conversation.
- Chats inside a collapsed project or chat group still require that group to be expanded manually.

## Install

Download `LitePark-v1.1.3-macOS.zip`, unzip it, and replace `LitePark.app` in Applications. Existing saved conversations and preferences are retained.

Requires Apple silicon and macOS 13 or later. This build is signed with a local development identity and is not Apple-notarized.

## Validation

The owner accepted the local sidebar reopening and restoration workflow. Release build, signature, installed-app, and public-download identities are verified separately for this release. No additional automated interaction tests were run.
