# LitePark 1.1.2 · Floating Panel Edge Refinement

Park it now. Pick it up later.

- The expanded panel has a native window shadow in both appearance modes.
- The light-mode outer border is thinner and clearer at 0.5pt. Dark-mode styling is unchanged.
- Board layout, controls, saved cards, and interactions are unchanged.

## Install

Download `LitePark-v1.1.2-macOS.zip`, unzip it, and replace `LitePark.app` in Applications. Existing saved conversations and preferences are retained.

Requires Apple silicon and macOS 13 or later. This build is signed with a local development identity and is not Apple-notarized.
